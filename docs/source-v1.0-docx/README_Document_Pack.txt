Assumptions to confirm during implementation:
- Currency defaults to Zambian kwacha only if confirmed by the project owner.
- Product quantity is whole units in the initial design; change to decimal quantities if needed.
- MVP businesses are owned by one user. Shared employee access is deferred.
- Returns are shown separately from sales; net sales must be explicitly defined before use.
